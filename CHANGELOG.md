# Changelog

All notable changes to the Bookdock Agent Skill are documented here.

## [Unreleased]

## [0.2.0]

### Added

- Read account-wide reading statistics for a date range and look up individual books’ reading data, notes, and reviews.
- Edit metadata and organization in a selected library, and revoke download links with the existing link permission.

### Changed

- Search by author, category, tag, or private shelf and sort across libraries. Use the selected library when fetching details or moving a private work to trash.

### Compatibility

- The new operations and query options require a Bookdock instance with the corresponding API support.

## [0.1.0]

### Added

- Use natural-language requests to browse Bookdock libraries, find book editions, and look up book details.
- Download EPUB files, create share links, upload EPUB or TXT books, and move private-library works to the trash.
- Install the Skill as a directory or ZIP. The API reference documents token scopes, request examples, and behavior for existing links and duplicate uploads.
