## [0.1.0]

### Added

- Use natural-language requests to browse Bookdock libraries, find book editions, and look up book details.
- Download EPUB files, create share links, upload EPUB or TXT books, and move private-library works to the trash.
- Install the Skill as a directory or ZIP. The API reference documents token scopes, request examples, and behavior for existing links and duplicate uploads.
